# AI Frontend Helper

A simple AI-powered frontend helper that generates ideas, code, and content for your projects. Built with React + Vite and deployed on Vercel.

## Features

- **Generate Ideas** - Get business ideas, names, and concepts from a prompt
- **Generate Code** - Get starter code / snippets based on your prompt
- **AI Assistant** - Ask anything and get a full AI answer
- **History** - All generations are saved automatically
    - Shows total count: `All Generations for {name} (X total)`
    - Click any history item to expand / collapse the full answer
    - No limit - keeps all history, not just last 5
- **Personalized** - Greets you by name

## Tech Stack

- React (Vite)
- JavaScript / JSX
- CSS
- Vercel for hosting / deployment

## How To Use

1. Open the live app
2. Enter your name
3. Type a prompt, e.g. `business idea for selling shoes in Lagos`
4. Choose a type: Ideas / Code / AI
5. Click **Generate**
6. Go to **History** to see all your past generations
7. Click any item to see the full answer
